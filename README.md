# Пианино на клавиатуре

Небольшой сайт без сборки для GitHub Pages. Откройте `index.html` или запустите локальный веб-сервер в папке проекта.

| Ряд | Белые клавиши | Чёрные клавиши |
| --- | --- | --- |
| Нижняя | Z X C V B N M , . / | S D G H J L ; |
| Верхняя | Q W E R T Y U I O P [ ] | 2 3 5 6 7 9 0 = |

Клавиши определяются через физические коды (`KeyboardEvent.code`), поэтому русская и другие раскладки играют те же ноты. Есть управление мышью и касанием, поддерживаются аккорды. Звук создаётся в браузере через Web Audio API.

После отпускания клавиши звук плавно затухает, поэтому короткие ноты не обрываются резко.

Если сайт встроен в iframe, нажмите кнопку над клавишами, чтобы передать ему фокус для игры с физической клавиатуры. Цветной индикатор показывает, активен ли фокус сейчас.

Для публикации на GitHub Pages выберите в настройках репозитория **Settings → Pages → Deploy from a branch**, ветку с сайтом и папку `/ (root)`.

## Tenori-on

Второй режим открывается по адресу [Tenori-on](https://graphnull.github.io/piano/?mode=tenorion).
Без параметра `mode=tenorion` сайт показывает пианино.

- Сетка 16×16: столбцы — шаги, строки — высота нот (пентатоника C).
- Нажимайте огни, чтобы включать и выключать ноты, затем нажмите «Играть».
- Выбор звука: колокольчик, электропиано, щипковый и синтезатор. «Сброс» останавливает и очищает сетку.
- Темп: 40–240 BPM, один шаг — шестнадцатая нота. Ноты плавно затухают.
- С клавиатуры: Tab — перейти к сетке, стрелки — выбрать огонь, Enter или пробел — переключить его.
- Режим помещается в iframe 376×376. Для вставки используйте URL с `?mode=tenorion`.
- Рисунок сохраняется до перезагрузки страницы. Запуск и остановка независимы для каждой вкладки.

### Общий темп

Вкладки сайта автоматически используют общий темп и фазу шестнадцатых нот. Измените темп в любой вкладке — остальные его подхватят. Запустите каждую вкладку кнопкой «Играть»: новый проигрыватель вступит на следующей общей границе шага, не с первого столбца. Инструменты и рисунки независимы.

`transport.mjs` — общий модуль для будущих ритмических режимов. `BroadcastChannel` передаёт состояние; `localStorage` хранит последний темп для новых вкладок, Web Locks упорядочивает одновременные изменения. Общая временная шкала переводится в локальное время AudioContext, звук планируется заранее. Фаза рассчитывается от Unix epoch исключительно по текущему времени и выбранному BPM. При смене темпа проигрыватель переходит на соответствующую общую сетку времени; прежняя фаза не сохраняется. На разных компьютерах достаточно вручную выбрать одинаковый BPM — моменты шагов и столбцы совпадут с точностью системных часов. Сервер и параметр BPM в URL не нужны.

Синхронизация рассчитана на один браузер и один сайт (origin и storage partition). iframe на другом родительском сайте может оказаться в отдельной группе из-за изоляции браузера. Автоматическая передача изменений BPM между устройствами потребует сервера; при ручном выборе одинакового BPM общий ритм рассчитывается без обмена данными. Используйте HTTP/HTTPS, например GitHub Pages, а не открытие index.html через file://. Браузер может заморозить фоновые вкладки; после возврата проигрыватель продолжит с актуального общего шага, пропустив задержанные ноты.
