# Пианино на клавиатуре

Небольшой сайт без сборки для GitHub Pages. Откройте `index.html` или запустите локальный веб-сервер в папке проекта.

| Ряд | Белые клавиши | Чёрные клавиши |
| --- | --- | --- |
| Нижняя | Z X C V B N M , . / | S D G H J L ; |
| Верхняя | Q W E R T Y U I O P [ ] | 2 3 5 6 7 9 0 = |

Клавиши определяются через физические коды (`KeyboardEvent.code`), поэтому русская и другие раскладки играют те же ноты. Есть управление мышью и касанием, поддерживаются аккорды. Звук создаётся в браузере через Web Audio API.

После отпускания клавиши звук плавно затухает, поэтому короткие ноты не обрываются резко.

Если сайт встроен в iframe, нажмите кнопку над клавишами, чтобы передать ему фокус для игры с физической клавиатуры. Цветной индикатор показывает, активен ли фокус сейчас.

Для публикации на GitHub Pages выберите в настройках репозитория **Settings → Pages → Deploy from a branch**, ветку с сайтом и папку `/ (root)`.

## Tenori-on

Второй режим открывается по адресу [Tenori-on](https://graphnull.github.io/piano/?mode=tenorion).
Без параметра `mode=tenorion` сайт показывает пианино.

- Сетка 16×16: столбцы — шаги, строки — высота нот (пентатоника C).
- Нажимайте огни, чтобы включать и выключать ноты, затем нажмите «Играть».
- Выбор звука: колокольчик, электропиано, щипковый и синтезатор. «Сброс» останавливает и очищает выбранную секцию.
- Темп: 40–240 BPM, один шаг — шестнадцатая нота. Ноты плавно затухают.
- С клавиатуры: Tab — перейти к сетке, стрелки — выбрать огонь, Enter или пробел — переключить его.
- Режим помещается в iframe 376×376. Для вставки используйте URL с `?mode=tenorion`.
- Рисунок сохраняется после каждого изменения и восстанавливается при перезагрузке. Каждая открытая вкладка восстанавливает свою партию; новая вкладка начинает с последнего сохранённого рисунка. «Сброс» сохраняет пустую сетку. Запуск и остановка независимы для каждой вкладки.

### Общий темп

Вкладки сайта автоматически используют общий темп и фазу шестнадцатых нот. Измените темп в любой вкладке — остальные его подхватят. Запустите каждую вкладку кнопкой «Играть»: новый проигрыватель вступит на следующей общей границе шага, не с первого столбца. Инструменты и рисунки независимы.

`transport.mjs` — общий модуль для будущих ритмических режимов. `BroadcastChannel` передаёт состояние; `localStorage` хранит последний темп для новых вкладок, Web Locks упорядочивает одновременные изменения. Общая временная шкала переводится в локальное время AudioContext, звук планируется заранее. Фаза рассчитывается от Unix epoch исключительно по текущему времени и выбранному BPM. При смене темпа проигрыватель переходит на соответствующую общую сетку времени; прежняя фаза не сохраняется. На разных компьютерах достаточно вручную выбрать одинаковый BPM — моменты шагов и столбцы совпадут с точностью системных часов. Сервер и параметр BPM в URL не нужны.

Синхронизация рассчитана на один браузер и один сайт (origin и storage partition). iframe на другом родительском сайте может оказаться в отдельной группе из-за изоляции браузера. Автоматическая передача изменений BPM между устройствами потребует сервера; при ручном выборе одинакового BPM общий ритм рассчитывается без обмена данными. Используйте HTTP/HTTPS, например GitHub Pages, а не открытие index.html через file://. Браузер может заморозить фоновые вкладки; после возврата проигрыватель продолжит с актуального общего шага, пропустив задержанные ноты.


## Драм-машина

Третий режим: https://graphnull.github.io/piano/?mode=drums . Восемь синтезированных ударных, 16 шагов. Нажимайте ячейки дорожек, затем «Играть». Чередование блоков по четыре шага показывает доли. Темп общий с Tenori-on, фаза от системного времени; рисунок сохраняется после перезагрузки. Стрелки выбирают ячейку, Enter и пробел переключают шаг. «Сброс» очищает сохранённый ритм. Режим рассчитан на iframe 376×376.

### Гамма, транспозиция и октава

Tenori-on: мажор, минор, дорийский и миксолидийский лады, мажорная и минорная пентатоники, хроматическая гамма. Сдвиг ±12 полутонов, октава ±2. Подписи строк и звук следуют настройкам, рисунок огней остаётся прежним. Настройки сохраняются отдельно для каждой вкладки при перезагрузке. По умолчанию оставлена прежняя мажорная пентатоника, чтобы старые рисунки звучали как раньше.

## Общая клавиатура всех инструментов

`keyboard-map.mjs` задаёт физические клавиши и MIDI-ноты; `live-keyboard.mjs` обрабатывает нажатия, отпускания, аккорды, потерю фокуса и экранные клавиши. Основа используется пианино, Tenori-on и драм-машиной. В секвенсорах кнопка «Клавиши» переключает вид на два ряда пианино, «Сетка» возвращает рисунок. Играть с физической клавиатуры можно в обоих видах, даже при остановленном секвенсоре. Кнопка ⌨ передаёт фокус iframe, точка показывает его состояние.

Tenori-on играет выбранным тембром, хроматически как пианино; транспозиция и октава действуют на клавиатуру, гамма определяет строки сетки. Удержание клавиш поддерживает ноту, отпускание плавно гасит её.

Драм-машина: C4/Z — бочка, D4/X — снейр, E4/C — хлопок, F4/V — хэт, G4/B — открытый хэт, A4/N — том, B4/M — крэш, C♯4/S — рим. Звуки повторяются по октавам; остальные чёрные клавиши дублируют ударные. Ручная игра не изменяет сохранённую сетку.

## Тема

Параметр `_theme=light` включает светлую тему, `_theme=dark` — тёмную (по умолчанию). Например: `?mode=tenorion&_theme=light`, `?mode=drums&_theme=dark`, `?_theme=light` для пианино.

## Четыре секции

Tenori-on и драм-машина имеют четыре независимых рисунка по 16 шагов: цикл из 64 шагов. Кнопки 1–4 выбирают секцию для редактирования. Ноты и удары отмечаются прямо в сетке; отдельного выбора аккорда нет. Красная точка показывает секцию, которая звучит сейчас. Можно редактировать другую секцию во время воспроизведения; подсветка столбца видна, когда открыта звучащая секция.

Воспроизведение идёт по кругу 1 → 2 → 3 → 4, с общей фазой времени и темпом обоих инструментов. При запуске инструмент вступает в текущую общую секцию и шаг. Все четыре рисунка и выбранная секция сохраняются при перезагрузке, в том числе отдельно для одинаковых iframe. «Сброс» очищает только выбранную секцию. Старый рисунок переносится во все четыре секции, чтобы существующие циклы продолжали звучать без изменения.

## Несколько одинаковых iframe

Сохранения рисунка, гаммы, транспозиции, октавы и тембра разделяются по позиции iframe в дереве родительских окон и доступному referrer. Родитель ничего не отправляет, менять URL не нужно. Общий темп остаётся общим. Для обычной страницы вне iframe сохранены прежние ключи хранения.

Порядок iframe должен оставаться стабильным: перестановка/удаление виджетов меняет соответствие сохранений. Учитываются и чужие iframe; если родитель скрывает свой путь в referrer, разные страницы одного родительского сайта могут использовать одинаковые позиции сохранений. Вложенные iframe различаются по полному пути позиций. Если браузер запрещает определение позиции или хранение, работа инструмента продолжается, но восстановление может быть недоступно.

## Синтезатор и свой семпл

Четвёртый режим: https://graphnull.github.io/piano/?mode=synth . Четыре секции по 64 шага (256 шагов в цикле), общий темп с остальными секвенсорами. Внутри секции кнопки диапазонов показывают 16 шагов за раз. Нажатие ставит ноту выбранной длины (1–64 шага), протягивание по строке задаёт её длину, повторное нажатие удаляет всю ноту. Стрелки и Enter управляют сеткой. Настройки и рисунки сохраняются отдельно для каждого iframe.

Три встроенных тембра (мягкий синт, бас, лид), фильтр, октава и общая клавиатура на 37 физических клавишах. Длинные ноты звучат непрерывно, отпускание плавное. При вступлении в середину длинной ноты проигрывается оставшаяся длительность.

«Микрофон» записывает до 10 секунд, повторное нажатие останавливает запись. Начальная и конечная тишина обрезаются автоматически. «Мой семпл» играет запись с изменением высоты; «Нота» задаёт исходную высоту записи, «Цикл» позволяет удерживать её дольше исходной длительности. Запись хранится локально в IndexedDB и не отправляется на сервер.

Микрофон требует разрешения браузера и HTTPS либо localhost. Если чужая родительская страница запрещает микрофон iframe, кнопка открывает отдельное окно записи (`mode=recorder`). Запись возвращается исходному виджету через проверенное сообщение окна, даже при изолированном хранилище iframe. Разрешите всплывающее окно; при отказе микрофона доступна кнопка «Записать в окне». Закрытие страницы освобождает микрофон.

### Свои ударные

Драм-машина имеет ещё четыре пустые дорожки «Семпл 1–4». Кнопка ● у дорожки записывает микрофон (до 10 секунд), ■ останавливает запись. Нажатие на название прослушивает готовый семпл. Семплы играются целиком с исходной высотой, без зацикливания. Физические клавиши Q/W/E/R (C5/D5/E5/F5) играют семплы 1/2/3/4; исходные Z–M и S продолжают играть стандартные ударные.

Все четыре записи сохраняются независимо в IndexedDB для данного виджета и используются во всех его секциях. Сброс секции очищает рисунок, но сохраняет записи. При обновлении прежние восемь дорожек и разные рисунки четырёх секций переносятся без потери; новые дорожки остаются пустыми. Для ограниченного iframe предусмотрено отдельное окно записи с возвратом звука в выбранную дорожку.
