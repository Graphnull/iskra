# Музыкальные виджеты

Статический сайт для GitHub Pages. Работает без сборки и сторонних библиотек. Все звуки создаются в браузере, записи ударных хранятся локально.

## Режимы

| Адрес | Инструмент |
| --- | --- |
| `/` | Пианино на 37 клавиш |
| `/?mode=guitar` | Гитара: шесть струн, пять ладов, щипки и бой |
| `/?mode=tenorion` | Tenori-on: четыре секции, гаммы и тембры |
| `/?mode=drums` | Драм-машина: восемь ударных и четыре записываемых дорожки |
| `/?mode=looper` | Лупер: запись микрофоном до восьми слоёв в общий цикл |
| `/?mode=synth` | Синтезатор: длинные ноты, формы волн, фильтр и ADSR |
| `/?mode=recorder` | Вспомогательное окно записи для драм-машины |

Тема: `&_theme=light` или `&_theme=dark`. Все основные режимы рассчитаны на iframe 376×376. Переходов между инструментами внутри виджета нет.

## Разработка

Требуется Node.js 22+ для проверок и Python 3 для локального сервера. Интерфейс написан на React со строгим TypeScript.

```sh
npm ci
npm run serve
npm test
npm run build
npm run check
```

Сайт откроется на `http://127.0.0.1:8781`. Используйте HTTP/HTTPS: модули, сохранения и микрофон не рассчитаны на `file://`.

`npm run check` проверяет строгие типы, собирает проект, проверяет синтаксис всех модулей, существование импортов, актуальность версий ресурсов и запускает тесты. Та же проверка выполняется GitHub Actions при push и изменениях PR. CSS компонентов находится рядом с их `.tsx` файлами, общие стили — в `src/styles/`, список подключений — в `src/styles.css`. `assets/styles.css` генерируется сборкой. После изменения кода или стилей выполните `npm run build`: TypeScript компилируется в `site/`, версии ресурсов вычисляются автоматически, включая вложенные импорты.

Подробности расширения проекта: [docs/architecture.md](docs/architecture.md).

## Игра и последовательности

| Ряд | Белые клавиши | Чёрные клавиши |
| --- | --- | --- |
| Нижний | Z X C V B N M , . / | S D G H J L ; |
| Верхний | Q W E R T Y U I O P [ ] | 2 3 5 6 7 9 0 = |

Используется `KeyboardEvent.code`, поэтому раскладка языка не влияет на ноты. Есть управление мышью, касанием и аккордами. Кнопка ⌨ показывает фокус и позволяет активировать клавиатуру. У синтезатора клавиатура работает и при фокусе на крутилке; нота отпускается при отпускании клавиши или уходе со страницы.

Все секвенсоры постоянно движутся по общему времени, включая состояние «Звук выключен». Кнопка «Звук включён / Звук выключен» управляет только аудио; при открытии звук выключен. Все секвенсоры имеют **четыре секции по 16 шагов**, цикл 64 шага. Один шаг — шестнадцатая нота. При запуске и каждом переходе сетка автоматически показывает звучащую секцию; её номер отмечен красной линией и точкой. Во время воспроизведения можно вручную открыть другую секцию для редактирования, до следующего перехода. Сброс очищает только выбранную секцию. Tenori-on и драм-машина при сбросе останавливаются, синтезатор продолжает воспроизведение.

Tenori-on поддерживает семь гамм, транспозицию и октавы. У синтезатора три пресета, четыре формы волны, фильтр, резонанс и две независимые огибающие ADSR: громкости и фильтра. В «Пульте» переключайте «Громкость» / «Фильтр»: точки A/D/R перетаскиваются по горизонтали, S — по вертикали; значения подписаны под кривой. Точки также управляются стрелками, Shift ускоряет изменение, Home/End ставят минимум/максимум. «Глубина фильтра» включает влияние его огибающей: 0% сохраняет обычный фильтр. Все настройки сохраняются после перезагрузки. Нажатие ставит ноту на один шаг или удаляет существующую; протягивание задаёт длину и сразу подсвечивает выделенный участок. При игре с клавиатуры подсвечивается строка соответствующей ноты. Записи семпла в синтезаторе нет.

Драм-машина: ● записывает до 10 секунд, ■ завершает запись, название дорожки прослушивает звук. Семплы 1–4 играются клавишами Q/W/E/R с исходной высотой. Они сохраняются независимо от рисунка и не удаляются при сбросе секции. Микрофон требует HTTPS/localhost и разрешения браузера. Если родительский сайт запрещает запись в iframe, используется отдельное окно с проверкой источника сообщения, origin и одноразовой сессии. Записи не отправляются на сервер.

Гитара: верхняя зона — гриф, нижняя — струны. На сенсорном экране удерживайте точки несколькими пальцами и проводите другим пальцем поперёк струн. Мышью зажатия закрепляются кликами; повторный клик снимает зажатие. Z/X/C/V/B/N щипают шесть струн независимо от языковой раскладки. Звук моделируется затухающей струной, без загружаемых семплов.

У пианино и гитары кнопка «Сетка» открывает четыре секции по 16 шагов. Нажатие добавляет или удаляет ноту; протягивание задаёт длину. Октава меняет высоты сетки. «Звук выключен / включён» управляет последовательностью, ручная игра остаётся доступна. При возврате на клавиши или гриф последовательность продолжает звучать. Сброс очищает выбранную секцию, рисунки инструментов сохраняются отдельно. Длинная нота гитары задаёт момент приглушения, сама струна естественно затухает.

## Сохранение и синхронизация

Ключи сохранений привязаны к позиции iframe в дереве окон и доступному referrer. Для одинаковых URL не требуется связь с родителем. Порядок виджетов должен быть стабильным: перестановка iframe меняет соответствие сохранений. При скрытом referrer или запрещённом хранилище восстановление может быть недоступно. Обычная вкладка сохраняет прежние ключи хранения.

При перезагрузке сначала используется корректное сохранение текущей вкладки (`sessionStorage`), затем последнее локальное сохранение (`localStorage`). Повреждённые данные не перекрывают исправную копию. Старые рисунки мигрируют без изменения ключей, записанные ударные остаются в IndexedDB.

Темп 40–240 BPM общий для вкладок одного origin и группы хранения. Фаза вычисляется из системного времени; запуск вступает на текущем общем шаге, после фоновой паузы просроченные ноты пропускаются. На разных компьютерах одинаковый BPM даёт общий ритм с точностью системных часов; изменение темпа между компьютерами автоматически не передаётся. Браузер может разделять хранилище iframe разных родительских сайтов.

## Публикация

GitHub Pages: **Settings → Pages → Deploy from a branch → нужная ветка → `/ (root)`**. В репозиторий входят готовые статические файлы; скомпилированный JavaScript лежит в `site/`; перед публикацией нужна локальная сборка. Перед отправкой рабочей ветки выполните `npm run build` и `npm run check`.

## Строгая типизация

`npm run typecheck` проверяет исходники без сборки. Включены `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, проверки возвратов и неиспользуемого кода. Данные из хранилищ и сообщений принимаются как `unknown` и проверяются перед использованием. Исходники редактируются в `src/`; файлы `site/` генерируются сборкой и включаются в коммит для GitHub Pages. CI также проверяет, что они соответствуют исходникам.

## React

`src/ui/` содержит общие компоненты фокуса, клавиатуры, управления воспроизведением, секций и сетки нот. Экраны инструментов находятся в `*-view.tsx`; контроллеры рядом с ними управляют аудио и сохранениями. React получает уведомления через `useSyncExternalStore`, а звук планируется независимо от рендеринга.

Сборка включает React в локальный `site/app.js`: браузеру не нужны npm, CDN или дополнительные серверы. `npm run format` форматирует TypeScript; `npm run format:check` проверяет формат. Тесты компонентов проверяют удержание нот при обновлении интерфейса, снятие обработчиков, фокус сетки и длину нот при протягивании.

После остановки записи в том же отдельном окне появляется редактор с волной. «Начало» меняется ползунком или нажатием/перетаскиванием по волне; «Громкость» — от 0 до 400%. Нажатие на название семпла открывает окно записи, «▶ Прослушать» играет с текущими настройками. Настройки сохраняются отдельно для каждой дорожки и iframe, применяются также к Q/W/E/R и секвенсору. Новая запись сбрасывает настройки своей дорожки.

Красная кнопка записи у дорожки сразу открывает отдельное окно. В нём нажмите «Начать запись», затем «Остановить»; настройте звук в этом же окне и нажмите «Сохранить в инструмент». Семпл и настройки вернутся в драм-машину, после подтверждения сохранения окно закроется. Если окно заблокировано, виджет предлагает разрешить всплывающие окна и повторить открытие.

На вкладке «Громкость» находится только ADSR громкости. Вкладка «Фильтр» предлагает LP (низкие), HP (высокие), BP (полоса) и Notch (вырез), а также режимы «Ползунок» / «ADSR». В ручном режиме частота задаётся ползунком; в ADSR «Начало» задаёт исходную частоту, «Глубина» — размах, а ползунок «Сейчас» показывает фактическую частоту последнего звучащего голоса и не редактируется. При первом включении ADSR с нулевой глубиной выставляются 80% и начало не выше 400 Гц. Для слышимого изменения тембра удобны «Пила» и «Прямоугольник»; синус содержит одну частоту. Тип фильтра и режим сохраняются.

При открытии окна через название семпла оно получает уже сохранённую запись и её настройки из выбранной дорожки. Для готовой записи сразу появляется волна; «Записать заново» переключает на новую запись. Пустая дорожка сразу предлагает начать запись.

## Лупер

`?mode=looper` записывает микрофон в общий цикл из 64 шагов. «Записать слой» начинает запись сразу после разрешения микрофона, с текущей позиции, без ожидания начала цикла. Повторное нажатие завершает слой; через один полный цикл запись заканчивается автоматически. Следующий слой добавляется поверх предыдущих. Используйте наушники, чтобы микрофон не записывал звук динамиков.

До восьми слоёв: волна, громкость 0–200%, отдельное приглушение и удаление. Записи сохраняются локально в IndexedDB, отдельно для каждого виджета. При смене BPM готовые слои меняют скорость и высоту вместе с темпом; активная запись отменяется с сообщением. Записи не отправляются на сервер.

Если микрофон запрещён в iframe, кнопка «Записать в отдельном окне» открывает запись без ограничений родительской страницы. Окно возвращает слой только исходному луперу с проверкой origin, источника и сессии; закрывается после подтверждения получения. Запись использует AudioWorklet и требует HTTPS/localhost.
